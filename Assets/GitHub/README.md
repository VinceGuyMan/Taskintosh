# Taskintosh — GitHub Starter Pack

All assets based on the locked Direction A logo.

## Avatars (repo / profile)
| File | Use |
|------|-----|
| `avatar-light.png` | Light theme avatar (white bg) |
| `avatar-dark.png` | Dark theme avatar (black bg) |
| `avatar-light-transparent.png` | Transparent light |
| `avatar-dark-transparent.png` | Transparent dark (white mark) |
| `avatar-light-{64,128,256,512,1024}.png` | Sized light avatars |
| `avatar-mono-black-{size}.png` | Pure black mono |
| `avatar-mono-white-{size}.png` | Pure white mono (dark UI) |

## Quick GitHub setup
1. **Repo avatar**: use `avatar-light-512.png` or `avatar-dark-512.png`
2. **Social preview**: Settings → Social preview → upload `og-light-1280x640.png`
3. **README**: embed `lockup-light.png` or `readme-hero-light.png` at the top
